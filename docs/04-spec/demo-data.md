## 9. Reset and demo-day checklist (DEC-031, US-015 rule 5)

**How the seed is (re)loaded**

| Build | How | Result |
|---|---|---|
| Local / test (`localhost`, `127.0.0.1`) | open with `?reset-demo` | DeskShare data deleted, seed for now loaded, parameter removed from the address bar |
| Deployed (public URL) | `?reset-demo` is **ignored**. Clear the site data in the browser, then open the app | first-open behaviour → seed for now |

**Clear site data** (also the fix for "Saved bookings could not be read in this browser. Clear site data to reload demo data."):

| Browser | Steps |
|---|---|
| Chrome / Edge desktop | on the app page: site-info icon left of the address → *Site settings* → *Delete data* (or DevTools → Application → Storage → *Clear site data*) |
| Chrome Android | ⋮ → *Settings* → *Site settings* → *All sites* → the app's host → *Delete data* / *Clear & reset* |
| Safari iOS | *Settings* → *Apps* → *Safari* (iOS 17: *Settings* → *Safari*) → *Advanced* → *Website Data* → swipe left on the app's host → *Delete* |

**Warning (RSK-011):** on GitHub Pages the host `hellatkacheva.github.io` is shared by all Pages sites of the account — also kit test C (GearLoan, `static`). Clearing its site data wipes the demo data of **both** apps in this browser; after clearing, open both apps once to reload their seeds. Each app uses its own storage key and never clears others' keys (I-11).
