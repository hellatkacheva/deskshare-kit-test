One page `app/public/index.html`, plain HTML / CSS / JS (ES modules), no framework. Two views by URL hash: `#/` **Book** (default) and `#/tomorrow` **Tomorrow** (US-013, Next band). Dialogs use `<dialog>`. All user-typed text is inserted with `textContent` — never `innerHTML` (REQ-035, US-011 "Name shown as plain text"). Dates are shown as `Thu 2026-10-22`. All asset paths are relative (GitHub Pages sub-path — I-16).

## 1. Global rules and fixed labels

| Rule / label | Detail | Serves |
|---|---|---|
| Demo banner | Fixed top line on **every** view and dialog, not dismissible: **"Demo — bookings are stored in this browser only."** | US-001 rule 3, REQ-031 |

## 3. Dialogs and states

### 3.1 Booking form (tap a free desk)

```
┌ Book desk F1-07 ──────────────────────┐
│ Thu 2026-10-22 · Floor 1              │
│ Your name                             │
│ [__________________________]          │ ← no maxlength; checkName() decides (I-15)
│ Names are self-reported — not for     │ ← US-012
│ emergency headcount.                  │
│ ☐ Show my name to colleagues          │ ← only if switch On (US-011)
│ ⚠ <message>                           │ ← storage.md §4
│                [Close]  [Book desk]   │
└───────────────────────────────────────┘
```
Book → `book()`. Error → message in the ⚠ line, the dialog stays open, the grid behind is re-rendered (`DESK_TAKEN`, `FLOOR_FULL`). Name errors are shown next to the name field (US-016 UI notes).

### 3.2 Confirmation (after `book()` ok)

```
┌ Booked ✓ ─────────────────────────────┐
│ Date: Thu 2026-10-22                  │
│ Desk: F1-07                           │
│ Please check in by 10:00 office time  │ ← contains "check in by <label>" (US-017)
│ (UTC+5) on Thu 2026-10-22.            │
│ Note your desk number — you need it   │
│ to check in or cancel                 │
│                              [Done]   │
└───────────────────────────────────────┘
```
No name in the confirmation (US-005 rule 9); no pending or approval state (REQ-007).

### 3.3 Booking actions — cancel / check-in (tap a taken or named desk)

```
┌ Desk F1-07 · Thu 2026-10-22 ──────────┐
│ Check-in deadline: 10:00 office time  │ ← today only (US-017 "Time label…")
│ (UTC+5)                               │
│ Your name (as booked)                 │
│ [__________________________]          │
│ Names are self-reported — not for     │ ← US-008, US-012
│ emergency headcount.                  │
│ ⚠ <message>                           │
│ [Check in]   [Cancel booking]         │
│                             [Close]   │
└───────────────────────────────────────┘
```

| Selected date | Shown | Serves |
|---|---|---|
| today | deadline line + **Check in** + **Cancel booking** | US-008, US-007, US-017 |
| future date | deadline line ("Check-in deadline: 10:00 office time (UTC+5) on Thu 2026-10-22") + the line "Check-in is only possible on the booking day." + **Cancel booking** only | US-008, US-017, I-6 |

Check in ok → "Checked in ✓" (or the info "This booking is already checked in."); Cancel ok → dialog closes, desk free. Errors in the ⚠ line; after `NO_BOOKING` / `RELEASED` the grid is re-rendered.

### 3.4 Unavailable dialog actions

Free desks have no cancel / check-in; taken desks have no booking form (US-004 rule 5, US-006 rule 5).

### 3.5 Full floor (`readDay` → `full: true`)

```
│ Floor 2: 25 booked · 0 left           │
│ ⚠ This floor is full for this day —   │
│ please pick another day or floor.     │
│ [taken][taken][taken][taken]…         │ ← no free tile; taken tiles open §3.3
```
No "book anyway", no waitlist (US-006 rules 2, 4).

### 3.6 Storage states (US-001, DEC-031)

| State | Shown under the banner | Hidden |
|---|---|---|
| Unavailable | "Bookings cannot be saved in this browser — browser storage is turned off." | booking form, Cancel, Check in (tiles show "free", tap does nothing) |
| Unreadable | "Saved bookings could not be read in this browser. Clear site data to reload demo data." | booking form, Cancel, Check in; counts and grid not rendered |

### 3.7 Empty date and after reload

| State | Shown | Serves |
|---|---|---|
| Date without bookings | `0 booked · 35 left` / `0 booked · 25 left`; all tiles free | US-003 "Date without bookings" |
| After reload | same data from storage; switch Off; default date selected | US-001, US-003, US-010 |

## 5. Demo switch (A/B group AB-1)

| Switch | Grid | Booking form | Notice above grid | Serves |
|---|---|---|---|---|
| Off (default, after reload) | Variant A — taken desks "taken" | no checkbox; `showName = false` | no | US-004, US-010, US-011 rule 2 |

Switching never changes stored data (US-010 rule 4).
