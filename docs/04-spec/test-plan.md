## 1. Test setup

| Type | Tool | Runs against | Clock | Data reset |
|---|---|---|---|---|
| **U** — unit | Vitest (node environment) | pure modules (`time.js`, `rules.js`, `seed.js`, `clock.js`) and `storage.js` with an in-memory fake `Storage` (can be set to throw or to hold broken JSON) | `now` passed as an argument | new fake storage per test |
| **E** — E2E | Playwright | `node scripts/serve.mjs` (no dependencies) serving `app/public/` at `http://127.0.0.1:4173` — `webServer` in `playwright.config.js` | `page.clock` (fake `Date` + timers; `runFor` for the minute tick); browser context `timezoneId: "Europe/Berlin"` so the office zone, not the device zone, is proven | new browser context per test (fresh `localStorage`); test data written before load by `test/e2e/helpers.js` → `page.addInitScript` |
| **S** — deployed smoke | Playwright project `deployed` (`BASE_URL` = public URL), run by the `deploy` step | the published static files | real clock | fresh context |
| **M** — manual | real phones: Chrome Android, Safari iOS (latest stable); 375 × 667 | the public URL | real clock | clear site data (demo-data.md §9) |

Playwright projects: `chromium-desktop` (all E specs) · `msedge` (channel `msedge`) · `mobile-chrome` (Chromium, 375 × 667, `isMobile`, `hasTouch`) · `mobile-webkit` (WebKit, iPhone SE descriptor 375 × 667) — the last three run `US-015.spec.js` only. Emulation does not replace the real-device check (M, I-17).

Commands (`app/package.json`): `npm test` (Vitest) · `npm run test:e2e` (Playwright, local) · `npm run test:smoke -- <url>` (project `deployed`) · `npm run serve`.
