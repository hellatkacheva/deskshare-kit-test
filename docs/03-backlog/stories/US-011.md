## Story
As an employee, I want to see on the desk grid where colleagues who agreed to it are sitting, so that I can sit near my team without anyone's attendance being exposed.

## Context and business rules
1. With the switch On, the booking form shows the checkbox **"Show my name to colleagues"**, unchecked by default. — REQ-027, DEC-011
2. With the switch Off, the checkbox is not shown and the booking is stored without consent. — REQ-027 (checkbox only in Variant B)
3. With the switch On, a taken desk shows the booker's name **only if that booking has consent**; other taken desks show "taken". — REQ-028, DEC-011
4. Names are shown only for the selected date; there is no list across days, no export and no print view. — REQ-028, NFR-003 `[W2 · Privacy]` "a list or export of "who came in which days" is not"
5. The counts view (US-003) never shows names. — NFR-002, ASM-015
6. Names are always shown as plain text, never as markup. — REQ-035, DEC-018
7. Wherever names are shown, the self-reported notice is shown too. — REQ-040, DEC-023
8. Accepted cost: a shown name can be re-typed to cancel or check in that booking. — RSK-010, ASM-012
9. **Source quote** for the ask: `[W3 · "Show me where my team sat" (new ask from Sam, via employee feedback)]` "show which desk their teammates booked"

## Acceptance criteria
```gherkin
Scenario: Consent checkbox with the switch On
  Given the switch is On
  When "Alex Morgan" opens the booking form for F1-07 on 2026-10-22
  Then the checkbox "Show my name to colleagues" is shown and unchecked

Scenario: Booking with consent shows the name (state effect)
  Given the switch is On
  When "Alex Morgan" books F1-07 for 2026-10-22 with the checkbox checked
  Then F1-07 on 2026-10-22 shows "Alex Morgan"

Scenario: Booking without consent shows "taken"
  Given the switch is On
  And "Jamie Lee" booked F1-08 for 2026-10-22 with the checkbox unchecked
  Then F1-08 on 2026-10-22 shows "taken" and not "Jamie Lee"

Scenario: Switch Off hides names even with consent
  Given "Alex Morgan" booked F1-07 for 2026-10-22 with consent
  When the switch is Off
  Then F1-07 shows "taken" and the name "Alex Morgan" is not on the screen

Scenario: No checkbox with the switch Off
  Given the switch is Off
  When "Sam Rivera" books F2-03 for 2026-10-22
  Then no consent checkbox is shown
  And when the switch is turned On, F2-03 shows "taken"

Scenario: Selected date only
  Given "Alex Morgan" booked F1-07 with consent for 2026-10-22 and 2026-10-23
  And the switch is On
  When the employee views 2026-10-22
  Then only the 2026-10-22 bookings are shown
  And the screen offers no list, export or print of names across days

Scenario: No names on the counts view
  Given the switch is On and "Alex Morgan" booked F1-07 with consent for 2026-10-22
  Then the counts view for 2026-10-22 shows no names

Scenario: Name shown as plain text
  Given the switch is On
  When "<b>Kim</b>" books F1-10 for 2026-10-22 with consent
  Then the F1-10 tile shows the text "<b>Kim</b>" literally, not in bold

Scenario: Notice wherever names are shown
  Given the switch is On and F1-07 shows "Alex Morgan" on 2026-10-22
  Then the notice "Names are self-reported — not for emergency headcount." is on the same screen
```
