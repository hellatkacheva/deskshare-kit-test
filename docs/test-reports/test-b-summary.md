## 1. Scope

Test B checks `/ba-sync`. A change to the source page must be found and classified, then traced to the affected items. After the BA's OK, only those items are reworked. It also checks the weekday watch (`setup-watch`).

The starting point was the end of test A: every step `reviewed`, page `65670` v2, child `458755` v1, Jira KAN-1…KAN-36.

The design plan (§8.1) has ten scenarios. Seven were run: B-neg, B0, B2, B4, B6, B7 and B7-err. B1 (C1 wording), B3 (C3 new decision) and B5 (C5 removal) were not run. Because B1 was skipped, the versions differ from the plan: B2 produced v4 (planned v5), and B4 produced v5 (planned v7).

Times: commits are in local time (UTC+5) and Confluence and GitHub times are in UTC. Both are given in UTC below.
