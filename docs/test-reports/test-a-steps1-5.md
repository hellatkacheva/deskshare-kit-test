## 4. Findings for the kit

### K-10 — show the Part A summary before Part B decisions

| | |
|---|---|
| **Observed** | `analyze-conflicts` wrote Part A to the file and went straight to the first CON question. The BA stopped the question tool and asked: «Сначала покажи сводку Part A одной таблицей: все CON, GAP, ASM, RSK — ID, суть в одну строку, варианты, твоя рекомендация». |
| **Why it matters** | The BA decides better with the whole picture: decisions interact — here CON-006 (desk) changed CON-001 variant B, and the ASMs depend on the CONs. A question about one CON before the overview also hides missing CONs (the BA spotted the desk-vs-floor conflict only in the summary). |
| **Proposal** | In `analyze-conflicts` Part B, step 0: show one table of all CON / GAP / ASM / RSK (ID · one-line gist · options · `Claude's recommendation`), then ask whether the BA wants to decide one by one or in one answer. Also state explicitly which observations were **not** raised as CON (e.g. "desk vs floor — recorded as GAP-007"). |

### K-11 — opposing positions of named people are a CON, not a GAP

| | |
|---|---|
| **Observed** | Two items with two named, opposing positions were recorded as gaps: desk vs. floor (Priya's "see a desk" + the problem "same desk twice" vs. Sam's "shouldn't be assumed for this phase") → GAP-007; "own" booking without login (Dana's "cancel their own booking" vs. no identity) → GAP-006. The reference had both as CON (ref CON-005, CON-006). In test A the BA had to raise CON-006 by hand; "own booking" stayed an ASM. |
| **Why it matters** | A GAP asks for a missing fact; a CON needs a trade-off decision with options. Recording a trade-off as a gap skips the options and lets an assumption decide it silently (golden rule 4). |
| **Proposal** | In `analyze-conflicts` Part A add a rule: if a gap can be answered in two ways that each match a quoted position of a named stakeholder (or a requirement vs. a recorded decision / OOS), it is a **CON** with both positions — not a GAP. Add a check to the quality bar: "every GAP is a missing fact; no GAP hides two quoted positions". Golden test: desk vs. floor and "own booking" must come out as CON. |

### Other observations (not numbered)

- Dangling sources (sample spreadsheet, fire-drill use case, peak demand) became RSK / SI but not GAP questions to the named owner — the reference asked them. Candidate rule: every missing input referenced in the sources yields a GAP to its owner.
- The critic missed the presence leak through the "name already has a booking" message (ref DEC-028). Candidate check for `backlog-reviewer`: privacy leaks through validation and error messages.
- Asking clock / time zone and seed / reset as OQs at step 4 removed both reference Blockers before the review — keep this in `write-stories`.
